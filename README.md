# Hemanth Kumar - OOP Innovative Assignment-I

**Student:** Hemanth Kumar  
**Course:** Object Oriented Programming

## Problems

- **Problem A:** Room and DeluxeRoom using constructors, inheritance and method overriding.
- **Problem B:** Abstract class Booking with abstract method confirmBooking(), extended by HotelBooking.
- **Problem C:** Handling ArithmeticException when the number of rooms is zero while calculating average room occupancy.

## OOP Concepts

- Classes and objects
- Constructors
- Inheritance
- `extends`
- `super()`
- Method overriding
- Abstract classes
- Abstract methods
- Exception handling
- `ArithmeticException`
